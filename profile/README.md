
# Rust Indonesia

**A community for Rust developers, learners, and open-source enthusiasts across Indonesia.**

Rust Indonesia is a community initiative dedicated to bringing together people interested in the Rust programming language throughout Indonesia.

Our goal is to create an inclusive environment where everyone can learn Rust, share knowledge, build projects, and contribute to the global Rust ecosystem.

## What We Do

- **Learning:** Beginner-friendly learning sessions and workshops.
- **Community:** Meetups, technical discussions, and knowledge sharing.
- **Open Source:** Collaborative projects and contributions to the Rust ecosystem.
- **Networking:** Connecting Rust developers, students, educators, and enthusiasts across Indonesia.

## Get Involved

We welcome everyone interested in Rust, regardless of experience level.

Community platforms and contact information will be announced as they become available.

## Community Principles

We aim to build a community that is:

- Welcoming and inclusive.
- Open to beginners and experienced developers.
- Collaborative and respectful.
- Committed to learning and open-source contributions.

We support a safe and friendly environment and encourage everyone to follow the [Rust Code of Conduct](https://rust-lang.org/policies/code-of-conduct).
